# RTSurvivor — инструкция для друга

Привет! Это сборник про игру **RTSurvivor** — RTS × Vampire Survivors.
Эта ветка (`friend-guide`) сделана специально для тебя: здесь готовая сборка,
инструкция и документация. Игровой код — в ветке `main`.

---

## 1. Быстрый старт (без сборки, 1 минута)

1. Нажми зелёную кнопку **Code → Download ZIP** на этой странице (проверь, что
   выбрана ветка `friend-guide`).
2. Распакуй архив.
3. Запусти `bin\rts.exe`. Всё, игра работает — установка не нужна,
   exe один и ничего не требует из системы.

> Если Windows Defender/SmartScreen ругнётся на неизвестного издателя —
> это нормально для самосборного exe: «Подробнее → Выполнить в любом случае».

Требования: Windows 10/11, любая видеокарта (игра рисует 2D-примитивы).

## 2. Как играть

**Цель:** продержись как можно больше ночных волн. Проигрыш — когда враги
разрушат Ратушу (большое здание в центре карты).

Цикл: **День (35 с)** — строй и нанимай → **Ночь** — отбивай волну →
**выбор 1 из 3 случайных бустов** → новый день, волны растут.

### Управление

| Клавиши | Действие |
|---|---|
| WASD / стрелки | перемещение камеры |
| Колесо мыши | масштаб (приближение к курсору) |
| 1–7 | выбрать здание для постройки, левый клик — поставить |
| ПКМ / Esc | отменить постройку |
| Q / W / E | нанять мечника / лучника / арбалетчика |
| 1–3 или клик | выбрать буст после волны |
| R | начать заново после поражения |

### Что строить (по приоритету)

1. **Фермы** — еда нужна на армию (и ратуша даёт лишь +1.2/с).
2. **Дома** — без них лимит армии 6 юнитов.
3. **Казарма** — без неё найм недоступен.
4. **Лесопилка и шахта** — расширяем экономику.
5. **Башни** — автоматически стреляют по врагам (радиус 230), хорошо прикрывают фланги.

### Советы

- Лучники — хребет обороны: дальность 170 против 22 у ближних врагов.
  Кучкуй армию у казармы, пусть волна подходит на убой.
- Арбалетчик (урон 26, дальность 210) открывается только бустом **Crossbow License**.
- С 3-й волны появляются Brute (толстые, медленные), с 5-й — Spitter
  (стреляют с 150 пикселей). К третьей волне имей хотя бы 6–8 юнитов и пару башен.
- Бусты накапливаются всю партию: 5 бустов Sharp Blades = юниты наносят
  в два раза больше урона.
- Ратуша не лечится. Если враги дошли до неё — бросай всё на защиту.

## 3. Хочу собрать сам (для любопытных)

Нужен MinGW-w64 с g++ (проект собирался gcc 16.2 UCRT, но подойдёт и свежий
winlibs/MSYS2). Компилятор должен лежать в пути **без пробелов и кириллицы** —
иначе линкер сломается.

```
build.bat        # из корня репозитория → bin\rts.exe
bin\rts.exe --selftest   # проверка симуляции без окна, должно напечатать PASS
```

Подробности — в `README.md` ветки `main` и в `docs/TECHNICAL.md`.

## 4. Что в этом репозитории

```
bin/rts.exe              ← готовая игра (запускай прямо отсюда)
assets/fonts/ptsans.ttf  ← шрифт с кириллицей для интерфейса
docs/
  GUIDE_FOR_FRIEND.md    ← этот файл
  TECHNICAL.md           ← техническая документация: архитектура, статы, формулы
  CPP_TOUR.md            ← обучалка по C++ на коде этой игры
```

Хочешь копаться в коде — переключись на ветку **`main`**, там исходники
(`src/main.cpp` — рендер/UI, `src/sim.cpp` — вся игровая логика, ~690 строк
на двоих). Рекомендую читать в паре с `docs/CPP_TOUR.md` — там каждая концепция
языка показана на живом коде проекта.
