# RTSurvivor — RTS × Vampire Survivors (MVP)

Упрощённый гибрид **They Are Billions / Diplomacy is Not an Option** с механикой
бустов из **Vampire Survivors**. День — строишь базу и нанимаешь армию,
ночь — отбиваешь волну врагов, после волны — выбор из 3 случайных бустов.
Цель — продержаться как можно больше волн.

Движок: **C++20 + raylib 6.2** (тонкая обёртка над OpenGL, летает на слабом железе).
Сборка: **MinGW-w64 (gcc 16.2, UCRT)** через `build.bat`.

> Почему MinGW, а не MSVC: Visual Studio установлен, но Windows SDK на машине
> нет, а его загрузчик не достукивается до серверов Microsoft с этой сети.
> Компилятор — портабельный winlibs MinGW, лежит в `C:\mingw64` (вне проекта,
> потому что GNU ld не переваривает пробелы и кириллицу в собственном пути).
> Хотите вернуться к MSVC — поставьте Windows 11 SDK через Visual Studio
> Installer, и можно переписать build.bat под `cl`.

## Сборка и запуск

```
build.bat          # компиляция → bin\rts.exe
bin\rts.exe        # игра
bin\rts.exe --selftest   # headless-прогон симуляции (баланс/регрессии)
```

> **Бинарные зависимости в репозитории не хранятся.** Перед первой сборкой
> скачайте raylib 6.2 (win64, вариант под ваш компилятор) с
> [github.com/raysan5/raylib/releases](https://github.com/raysan5/raylib/releases)
> и положите заголовки в `third_party/raylib_mingw\include`, статическую
> библиотеку — в `third_party/raylib_mingw\lib` (build.bat использует именно
> MinGW-вариант `libraylib.a`). Шрифт PT Sans положите в
> `assets/fonts/ptsans.ttf`. Готовая сборка без этих телодвижений — в ветке
> `friend-guide`.

## Управление

| Клавиши | Действие |
|---|---|
| WASD / стрелки | перемещение камеры |
| Колесо мыши | масштаб |
| 1–7 | выбрать здание для постройки, клик — поставить |
| ПКМ / Esc | отменить постройку |
| Q / W / E | нанять мечника / лучника / арбалетчика (нужна казарма) |
| 1–3 или клик | выбор буста после волны |
| R | заново после поражения |

## Экономика

- **Ратуша** — центр базы, +1.2 еды/с, лимит населения 6. Если пала — конец игры.
- **Дом** — +4 к лимиту населения.
- **Ферма** — +2 еды/с. **Лесопилка** — +2.5 дерева/с. **Шахта** — +1.8 золота/с.
- **Казарма** — найм юнитов. **Башня** — автоатака по врагам в радиусе 230.

## Структура

```
src/sim.h, src/sim.cpp   — чистая симуляция (без raylib): можно гонять headless
src/main.cpp             — окно, рендер, UI, самотест
docs/                    — TECHNICAL.md (техдок), CPP_TOUR.md (экскурс в C++)
third_party/raylib/      — бинарники raylib 6.2 (MSVC) — скачать, см. выше
third_party/raylib_mingw/— бинарники raylib 6.2 (MinGW) — скачать, см. выше
assets/fonts/            — PT Sans (кириллица)
```

> Ветка `friend-guide` — готовая сборка и инструкция для друга:
> скачать ZIP → запустить `bin\rts.exe`.

## Оптимизация (заложено в архитектуру)

- Фиксированный шаг симуляции 60 Гц, отделённый от рендера.
- Пространственная сетка (uniform grid) для поиска целей — O(1) в среднем вместо O(n²).
- Placeholder-арт прямоугольниками/кружками → позже спрайт-атлас и инстансинг,
  тысячи юнитов в одном draw call.
- `sim.cpp` не зависит от рендера — профилирование и баланс без окна.
